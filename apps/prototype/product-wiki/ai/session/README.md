## 目标与价值

AI 会话让用户在统一入口里浏览历史协助、继续追问，并在右侧工作台处理结构化结果。会话聊天走本机编码 Agent，用户可在对话区切换当前选用的 Agent，无需独立 AI 设置页。业务页（如目标详情、任务详情）只负责发起，不再承载完整的拆解审阅界面。

<!-- product-ref: ai.session.view.shell -->
### AI 会话壳层

壳层为三栏布局：左侧会话列表、中间对话、右侧工作台容器。打开 `/ai` 且无选中会话时，中间与右侧可为空态；选择会话或从目标/任务发起后填充对应内容。

<!-- product-ref: ai.session.view.session-list -->
### 会话列表

列表展示会话标题、可选绑定目标或任务名称与最近更新时间，支持新建无绑定会话与切换当前会话。当前会话需高亮。

<!-- product-ref: ai.session.view.conversation -->
### 会话对话

对话区按时间展示用户与助手消息。新消息到达且用户仍贴在底部时自动跟随；用户上翻后停止跟随，并出现回到底部入口。文本块以气泡呈现；工具调用过程可折叠查看参数与结果；含工作台结构化块的消息提供可点击入口以打开对应工作台，同一会话可有多块工作台且互不替代。底部输入区上方为消息列表，输入区底部为编码 Agent 选择器；可发送追问，发送走当前选中且可用的编码 Agent。流式生成时发送按钮变为停止。追问仅追加文本往返，不自动打开或替换工作台。追问文案也可由拆解工作台「对已选追问」预填进输入框，用户确认后再发送，语义仍是通用对话追问。会话页是通用对话壳层，不提供面向特定能力的工具栏操作（如重新生成拆解）。绑定目标或任务的发起消息中，业务对象名称可点击进入对应详情。

<!-- product-ref: ai.session.view.workspace-host -->
### 工作台容器

容器仅在用户显式打开某条消息的工作台块后挂载功能界面。无激活块时显示空态提示。未知工作台类型时给出不可用提示，而不是静默失败。切换会话时关闭当前工作台。

<!-- product-ref: ai.session.view.agent-picker -->
### 编码 Agent 选择器

对话区提供本机编码 Agent 切换，展示名为当前选用项。本版为 ChatGPT（需本机已安装 ChatGPT 应用并登录）。其它 Agent 可随本机探测结果进入列表。未安装或未登录的项禁用，并说明原因。没有独立的 AI 设置页，选用偏好即在此切换。

<!-- product-ref: ai.session.interaction -->
## 交互语义

工作台激活状态仅由用户点选决定：点消息上的打开入口后挂载对应块；未点选或切换会话后右侧为空。同一会话可存在多条含工作台块的消息，不会默认取最后一条。从目标或任务进入时创建或打开绑定会话并产出拆解工作台块，但不自动打开右侧；绑定发起与普通发送使用同一套当前选用且可用的编码 Agent。切换编码 Agent 只影响之后的发送，不改写已有消息，也不自动打开工作台。工作台内「对已选追问」只预填并发送对话文本，不改变当前工作台挂载状态。生成不等于采纳。

<!-- product-ref: ai.session.rule.workspace-dispatch -->
### 工作台分发

消息内容可包含文本块与工作台块。工作台块携带类型标识与载荷；用户点选后，容器按类型打开对应工作台。当前产品实现目标拆解（`goal.decompose`）与任务拆解（`task.decompose`）。未点选时右侧保持空容器；切换会话关闭工作台。

<!-- product-ref: ai.session.rule.goal-bound-start -->
### 目标绑定发起

用户从目标详情发起 AI 拆解时，系统查找已绑定该目标的会话；若有则打开最近一条，若无则新建标题含目标名的绑定会话，写入用户发起消息与助手拆解结果（含工作台块），且不自动打开工作台。发起所用编码 Agent 与对话区当前选用且可用的 Agent 相同。发起消息展示「请帮我拆解」与可点击的目标名称，点击后进入该目标详情。目标详情不再打开独立拆解抽屉。

<!-- product-ref: ai.session.rule.task-bound-start -->
### 任务绑定发起

用户从任务详情发起 AI 拆解时，系统查找已绑定该任务的会话；若有则打开最近一条，若无则新建标题含任务名的绑定会话，写入用户发起消息与助手任务拆解结果（含任务拆解工作台块），且不自动打开工作台。发起所用编码 Agent 与对话区当前选用且可用的 Agent 相同。发起消息展示「请帮我拆解」与可点击的任务名称，点击后进入该任务详情。

<!-- product-ref: ai.session.rule.agent-switch -->
### 编码 Agent 切换

发送始终走当前选中且可用的编码 Agent。在对话区切换 Agent 只影响之后的发送：已有消息保持原样，不会自动打开工作台。切换后，该会话不再续跑上一 Agent 的对话线程，之后每一轮作为新的开始。未安装或未登录的项不可选，并说明原因。从目标或任务绑定发起与普通发送共用同一套所选 Agent。生成结果不等于已采纳，工作台仍需用户点选才打开。
